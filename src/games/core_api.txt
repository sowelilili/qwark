# The core functions a game may call (SPEC-game-modules.md section 4.4).
#
# tools/coreapi.py turns this list into
#
#   src/games/core_api.h     struct core_api, one function pointer per line below
#   src/games/core_import.h  the names a game's source uses, renamed to the wrappers
#   src/games/core_import.c  one wrapper per line: qimp_<name>(...) calls Q->api
#   src/core/core_export.c   the table itself, the core's real functions
#
# Every build that reaches its games through core_api (QWARK_GAME_IMPORT: the
# host builds and a test module's game modules) goes through these and nothing
# else, which `python -I tools/coreapi.py nmcheck` holds the host's game objects
# to. A line is a prototype as the core's header spells it. `[COND]` puts it
# under #ifdef COND. A variadic one names the va_list function the table holds
# instead, after `->`. `#include` lines are copied into core_api.h.
#
# Change this file, then run `python -I tools/coreapi.py` and commit what it
# writes; test/run.sh fails while the generated files are stale.
